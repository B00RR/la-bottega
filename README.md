# La Bottega

Gioco mobile in italiano: la bottega di un riparatore, in three.js. Ora c’è il tutorial giocabile (torcia e telecomando).

Da dove si parte: [STATO_PROGETTO.md](STATO_PROGETTO.md).

Il design del tutorial è in [docs/DESIGN_TUTORIAL.md](docs/DESIGN_TUTORIAL.md). Le licenze sono in [docs/LICENZE_ASSET.md](docs/LICENZE_ASSET.md).

```bash
npm install
npm run dev
```

Sul telefono si apre lo stesso indirizzo, in verticale. La build di produzione è `npm run build` e `npm run preview`. La prova che gioca il tutorial è `npm run test:e2e`.

Pubblicato su <https://b00rr.github.io/la-bottega/> quando `main` viene aggiornato.
